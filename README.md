# SM5703/SM5705 power-supply port for postmarketOS

Highly experimental mainline/postmarketOS mfd/power-supply work for the Samsung Galaxy devices with SM5703/SM5705, thats try to be generic reference driver.

This repository contains the code and notes needed to reproduce the work, but new one generated by AI.

The tested result was:

```text
/sys/class/power_supply/sm570x-fuelgauge
/sys/class/power_supply/sm570x-charger
```

and manual charge control:

```sh
echo 1 > /sys/class/power_supply/sm570x-charger/charge_control_limit  # stop charging
echo 0 > /sys/class/power_supply/sm570x-charger/charge_control_limit  # resume charging
```

When charging was stopped with the USB cable connected, the charger reported `status=Not charging` and the fuel-gauge current became negative. When charging was resumed, the current became positive again.

```text

  sm570x_fuelgauge.c        Minimal fuel-gauge driver

  sm570x-store-mode.init    OpenRC init script

  apply-to-kernel-tree.sh   Copy driver sources and edit Kconfig/Makefile
  install-openrc-service.sh Install 40-60% store-mode service on target
  build-pmbootstrap.sh      Rebuild the postmarketOS kernel package
  deploy-to-device.sh       Copy modules and DTB to a running phone over SSH
  test-charge-control.sh    Manual runtime tests

  PORTING_NOTES.md
  KNOWN_ISSUES.md
```

## Important status

This is not an upstream-ready driver. It is not tested yet.

## Quick start

On the PC, point `KERNEL_TREE` at the msm8916 kernel checkout:

```sh
export KERNEL_TREE="$HOME/j5x-power-port/linux-msm8916"
export PMOS_KERNEL_PACKAGE="$HOME/.local/var/pmbootstrap/cache_git/pmaports/device/testing/linux-postmarketos-qcom-msm8916"
./scripts/apply-to-kernel-tree.sh "$KERNEL_TREE"
./scripts/build-pmbootstrap.sh "$PMOS_KERNEL_PACKAGE"
```

Then deploy to a running phone over Wi-Fi SSH:

```sh
./scripts/deploy-to-device.sh 192.168.1.21
```

On the phone, after reboot:

```sh
sudo su
./tmp/test-charge-control.sh
```

Install the 40-60% OpenRC store-mode service:

```sh
sudo su
sh /tmp/install-openrc-service.sh
```

## Runtime checks

```sh
lsmod | grep sm5703
ls /sys/class/power_supply/sm570x-fuelgauge
ls /sys/class/power_supply/sm570x-charger
```

Check state:

```sh
echo "cap=$(cat /sys/class/power_supply/sm570x-fuelgauge/capacity) limit=$(cat /sys/class/power_supply/sm570x-charger/charge_control_limit) current=$(cat /sys/class/power_supply/sm570x-fuelgauge/current_now) temp=$(cat /sys/class/power_supply/sm570x-fuelgauge/temp)"
```
